# Stopwatch

A stopwatch web application built with HTML, CSS, and JavaScript. This project features a custom dark-themed interface with timer controls and lap tracking.

## Features

- **Start** — Starts the stopwatch.
- **Stop** — Pauses the stopwatch while preserving elapsed time.
- **Reset** — Resets the timer and clears recorded laps.
- **Lap Tracking** — Records the current elapsed time without stopping the stopwatch.
- **Custom UI** — Dark background, color-coded buttons, and separate timer and lap containers.
- **Responsive Layout** — Adapts the layout for smaller screens.

## Languages & Technologies

- **HTML** 
- **CSS(Flexbox)** 
- **JavaScript**
